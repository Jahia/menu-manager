# menu-manager Changelog

## 1.0.0

* Added a Menu component with four views: horizontal bar, mega menu, vertical list and columns.

* Added an Edit this menu link on the Menu component in Page Builder, opening jContent > Menus on its menu.

* Added menu labels translated per language, with a fallback language and items hidden in chosen languages.

* Added promotions on top-level items, shown in the mega menu with an image, a text and a button.

* Added menus that leave out every item and page the visitor is not allowed to read.

* Added the Menus screen in jContent to build menus of pages, sections and links, ordered by drag and drop.
